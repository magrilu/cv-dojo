Seven points, up to three fundamental matrices

With eight generic correspondences, the linear system leaves one null direction. With only seven,

\[ \mathsf{A}\in\mathbb{R}^{7\times9},\qquad \dim\ker \mathsf{A}=2. \]

So the linear epipolar constraints define a pencil of matrices. Imposing \(\det \mathsf{F}=0\) selects up to three rank-two members of that pencil.

We again use only points on the Origami House. Seven are used to fit the minimal problem and one roof point is held out to expose the ambiguity.

# --- The eight-point algorithm ---------------------------------------------
# These stay in the notebook: they are the subject, not the scaffolding.

def normalize_points(x):
    """Hartley normalization: centroid at the origin, mean distance sqrt(2)."""
    c = x[:, :2].mean(axis=0)
    d = np.sqrt(((x[:, :2] - c) ** 2).sum(axis=1)).mean()
    s = np.sqrt(2.0) / d
    T = np.array([[s, 0, -s * c[0]], [0, s, -s * c[1]], [0, 0, 1.0]])
    return (T @ x.T).T, T


def design_matrix(x, xp):
    """One row per correspondence, expressing x'^T F x = 0."""
    u, v = x[:, 0], x[:, 1]
    up, vp = xp[:, 0], xp[:, 1]
    return np.column_stack([up * u, up * v, up,
                            vp * u, vp * v, vp,
                            u, v, np.ones(len(x))])


def eight_point(x, xp, enforce_rank2=True):
    xn, T = normalize_points(x)
    xpn, Tp = normalize_points(xp)
    A = design_matrix(xn, xpn)
    _, S, Vt = np.linalg.svd(A)
    Fn = Vt[-1].reshape(3, 3)
    if enforce_rank2:
        U, s, VtF = np.linalg.svd(Fn)
        s[-1] = 0.0
        Fn = U @ np.diag(s) @ VtF
    F = Tp.T @ Fn @ T
    return F / np.linalg.norm(F), A, S


def point_line_distance(x, l):
    """Distance in pixels from a homogeneous point to a homogeneous line."""
    return abs(x @ l) / np.linalg.norm(l[:2])


def epipoles(F):
    """e is the right null vector of F, e' the right null vector of F^T."""
    _, _, Vt = np.linalg.svd(F)
    e = Vt[-1] / Vt[-1][2]
    _, _, Vt = np.linalg.svd(F.T)
    ep = Vt[-1] / Vt[-1][2]
    return e, ep

Every matrix in the pencil

\[ \mathsf{F}(\lambda)=\mathsf{F}_1+\lambda \mathsf{F}_2 \]

satisfies the seven linear equations. Rank two adds

\[ \det \mathsf{F}(\lambda)=0. \]

Because each entry is linear in \(\lambda\), the determinant is a cubic polynomial.

2. Solve the cubic

We evaluate the determinant at four values of \(\lambda\) and recover the cubic coefficients. This keeps the code transparent without hiding the geometry in a black-box solver.

def determinant_cubic(F1,F2):
    lam=np.array([0.,1.,-1.,2.])
    y=np.array([np.linalg.det(F1+l*F2) for l in lam])
    V=np.column_stack([lam**3,lam**2,lam,np.ones_like(lam)])
    return np.linalg.solve(V,y)

coef=determinant_cubic(F1n,F2n)
roots=np.roots(coef)
real_roots=sorted([r.real for r in roots if abs(r.imag)<1e-8])
print('cubic coefficients =',coef)
print('roots =',roots)

For this real house configuration the cubic has three real roots. Thus the correct minimal-solver output is three candidate epipolar geometries, not one.

Fs=[]
for lam in real_roots:
    Fn=F1n+lam*F2n
    # det(Fn)=0 already; the SVD cleanup removes only floating-point residue.
    Uq,sq,Vtq=np.linalg.svd(Fn); sq[-1]=0.; Fn=Uq@np.diag(sq)@Vtq
    Fq=Tp.T@Fn@T; Fq/=np.linalg.norm(Fq)
    Fs.append(Fq)
for j,Fq in enumerate(Fs,1):
    residuals=np.array([xp[i]@Fq@x[i] for i in train])
    print(f'candidate {j}: rank={np.linalg.matrix_rank(Fq,tol=1e-10)}, max training residual={np.max(np.abs(residuals)):.3e}')

4. The held-out roof point breaks the ambiguity

Now use \(\mathbf{x}_7\leftrightarrow\mathbf{x}_7'\) — a real point on the roof ridge that was not used to compute the three candidates.

For each candidate, map the held-out point to its epipolar line and measure the point-to-line distance in both images.

held=[]

The eighth match is therefore not merely “one more row”. In a generic configuration it selects among the finite solutions left by the seven-point minimal problem.

With noisy feature matches we would not normally choose a model from one held-out point. The seven-point solver is instead useful inside RANSAC/MSAC: draw a minimal sample, generate one or three candidate \(\mathsf{F}\)’s, and score them on the full correspondence set.

5. The seven-point algorithm in one box

Given seven correspondences \(\mathbf{x}_i\leftrightarrow\mathbf{x}_i'\):

  1. Normalize the points in both images.
  2. Build the \(7\times9\) matrix \(\mathsf{A}\).
  3. Find two nullspace basis matrices \(\mathsf{F}_1,\mathsf{F}_2\).
  4. Write \(\mathsf{F}(\lambda)=\mathsf{F}_1+\lambda \mathsf{F}_2\).
  5. Solve the cubic \(\det \mathsf{F}(\lambda)=0\).
  6. Keep the real roots.
  7. Undo the image normalizations.

In the generic case the output is one or three real fundamental matrices.

Connection among the three notebooks

\[ \begin{array}{ccl} 8\text{ points} &:& \text{one linear null direction, then rank-two projection},\\[1mm] 7\text{ points} &:& \text{two null directions + a cubic rank constraint},\\[1mm] \text{critical data} &:& \text{the nullspace grows because the geometry itself is ambiguous.} \end{array} \]

The number of points is only half of the story. Their geometric configuration on the scene decides how much two-view geometry they actually determine.
